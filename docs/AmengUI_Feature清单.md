# AmengUI Feature 清单

> 更新日期：2026-08-25
>
> 这份清单用于区分 AmengUI Shell、amsys、pacman 和第三方应用的职责。
> 状态约定：`[x]` 已完成，`[~]` 部分完成或需要验证，`[ ]` 未开始。

## 结论

AmengUI 的下一阶段不是继续增加零散设置页，而是完成三件事：

1. 把无 Explorer 环境下的 Shell 基础体验做稳定；
2. 把 `.app` 启动器、文件关联和扩展接口定义清楚；
3. 让 pacman 负责应用包和可选扩展，而不是把第三方功能继续塞进核心。

## P0：必须完成的 Shell 基础

### 1. 首次运行与发布包

- `[ ]` 安装包首次启动自动创建 `rootdir/`、用户配置和默认身份数据。
- `[ ]` 已存在旧版配置时执行版本迁移，不覆盖用户桌面布局、主题和通知。
- `[ ]` 打包后的资源路径、外部 amsys 路径和 PowerShell 路径做一次完整冒烟测试。
- `[ ]` 生产构建默认关闭 DevTools，并在缺少依赖时显示可操作错误。
- `[ ]` 增加“启动失败后恢复桌面”的最小 watchdog / launcher 闭环。

验收：从全新 Windows 用户目录安装后直接启动，不需要手工创建目录或修改配置；主进程异常退出后能自动恢复或明确提示。

### 2. 无 Explorer 环境的窗口与最小化

- `[~]` 任务栏已经有独立窗口列表和切换逻辑，需在无 Explorer 的真实环境验证。
- `[ ]` 原生窗口最小化时立即 `SW_HIDE`，不留下屏幕底部标题栏碎片。
- `[ ]` 任务栏按钮支持运行中、已最小化、当前激活三种状态。
- `[ ]` 关闭、恢复、激活和多窗口分组行为在 Win32、UWP/商店应用上分别定义。
- `[ ]` 将窗口置底从 2 秒轮询迁移到 `SetWinEventHook`，减少抖动和 PowerShell 冷启动。
- `[ ]` 覆盖多显示器、DPI、虚拟桌面和窗口跨屏移动场景。

验收：关闭 Explorer 后启动记事本、浏览器和设置窗口；最小化不出现底部残留，点击 AmengUI 任务栏按钮可稳定恢复和切换。

### 3. 电源、权限与异常反馈

- `[~]` 关机/重启调用已经存在，需要确认弹窗、取消和失败反馈统一。
- `[ ]` 检测管理员权限；亮度、蓝牙、Wi-Fi、飞行模式失败时显示原因，而不是静默回弹。
- `[ ]` Shell 模式、锁屏、注销、关机之间增加状态互斥，避免重复启动或恢复错误窗口。
- `[ ]` 临时 PowerShell 脚本在成功、失败和异常退出路径都清理。

## P1：Windows 集成

### 4. 托盘 / 通知区域

- `[ ]` 先完成 AmengUI 自建通知区域：图标、tooltip、左键菜单、右键菜单、溢出菜单。
- `[ ]` 定义扩展托盘 manifest：`id`、`icon`、`tooltip`、菜单树、点击事件和生命周期。
- `[ ]` pacman 安装的扩展可以注册和注销托盘项，不需要修改 AmengUI 核心代码。
- `[ ]` 明确原生第三方托盘的产品边界：无 Explorer 时第一阶段不承诺接管。
- `[ ]` 单独评估原生托盘劫持（DLL/IAT hook、32/64 位、UAC、PPL/HVCI、杀软误报）；只有在自建托盘稳定后立项。

验收：无 Explorer 时 AmengUI 自己的托盘图标和扩展图标正常显示、点击和退出；原生劫持失败不会影响 Shell 稳定性。

### 5. 系统通知

- `[x]` 已接收 Windows 系统通知：Windows PowerShell 5.1 + `UserNotificationListener` 监听器已接入。
- `[x]` 通知持久化、未读数、消息面板、全部已读和清空已实现。
- `[~]` 补充通知权限/监听器不可用状态提示，以及首次启动基线去重验证。
- `[~]` 验证用户切换时通知存储隔离，避免跨用户显示旧通知。
- `[ ]` 定义应用通知 API 和 `.app` 中的通知权限声明。
- `[ ]` 增加通知点击回调或关联窗口激活协议。

验收：系统通知只出现一次；用户切换后不串通知；监听器不可用时消息面板显示明确状态；应用通知可定位到对应窗口或应用。

## P1：`.app` 应用模型

### 6. `.app` 清单与启动

- `[x]` 从 `/usr/share/applications` 读取 `.app` 并显示在开始菜单。
- `[x]` 支持应用图标提取、桌面快捷方式、隐藏、卸载和任务栏应用身份。
- `[ ]` 完善字段：`args`、`cwd`、`env`、`terminal`、`startupWMClass`、`mimeTypes`、`protocols`。
- `[ ]` 明确 Unix 路径和 Windows 路径的解析优先级，避免安装器写入绝对路径后失效。
- `[ ]` 为无效 JSON、缺失 exe、图标提取失败提供单项错误状态，不阻塞整个开始菜单。

### 7. `.app` 文件关联

- `[ ]` 注册 `.app` 文件关联：双击 `.app` 时由 AmengUI 或 pacman 打开预览/安装流程。
- `[ ]` 支持右键“打开方式”和默认处理程序设置。
- `[ ]` 处理命令行参数、多个文件拖入和路径中包含空格/非 ASCII 字符。
- `[ ]` 卸载 pacman 或 AmengUI 时清理关联注册表项，不删除用户自定义关联。
- `[ ]` 与 `.aup` 关联统一协议；`.aup` 负责包安装，`.app` 负责应用清单/启动器。

验收：双击、拖拽和命令行打开 `.app` 均能进入正确流程；卸载后关联可恢复或明确提示；`.app` 和 `.aup` 不混淆。

## P2：amsys 与终端体验

- `[~]` Node 原生路径转换已稳定使用；`amsys --pipe` 仍未恢复。
- `[ ]` 决定 `--pipe` 是长期协议还是废弃，并补兼容性测试，不保留模糊的双实现状态。
- `[ ]` 提供真正可用的 Unix 终端：历史、Tab 补全、管道、`/home`、`/etc`、`/usr/share/applications` 路径贯通。
- `[ ]` 映射环境变量和 `$PATH`，让 `.app`/amsys 命令可从终端调用。
- `[ ]` Shell 模式增加 UI 退出入口，同时保留终端 `exit` 语义。

验收：用户可以在终端中浏览虚拟根、读取用户文件、启动 `.app`，并在 Shell 模式和桌面模式之间可靠切换。

## P2：质量与可维护性

- `[ ]` 为路径转换、用户切换、通知存储、应用列表、窗口状态和 `.app` 解析补自动化测试。
- `[ ]` 增加无 Explorer、普通权限、管理员权限、双显示器和高 DPI 的手工验收矩阵。
- `[ ]` 收敛常驻 PowerShell 服务，统一超时、取消、缓存和错误格式。
- `[ ]` 记录关键 IPC 的版本和错误码，减少渲染层依赖隐式返回值。
- `[ ]` 更新 README 与 ReleaseNotes，删除已完成功能的过时“未实现”描述。

## pacman 负责的范围

- `[x]` `.aup` 载入、预览和安装/卸载流程。
- `[ ]` 依赖解析、版本策略、仓库索引、签名校验和回滚。
- `[ ]` 应用包升级、降级、重装和安装日志。
- `[ ]` 扩展 manifest：托盘、控制中心页、开始菜单分区、文件关联和通知声明。
- `[ ]` 扩展权限、启停、卸载清理和与 AmengUI API 版本协商。

## 明确暂不承诺

- `[ ]` 在无 Explorer 环境下无条件接管所有第三方原生托盘图标。
- `[ ]` 通过 DLL 注入绕过 UAC、PPL、HVCI 或杀软拦截。
- `[ ]` 将所有第三方应用功能内置到 AmengUI 设置页。

这些项目可以单独立项，但不应阻塞 AmengUI 核心 Shell 和 pacman 扩展平台的交付。

## 推荐执行顺序

1. 无 Explorer 的最小化/任务栏验收与窗口事件化。
2. 首次运行、打包资源、watchdog 和权限错误处理。
3. 自建托盘区域与扩展 manifest。
4. `.app` 字段完善和 `.app` 文件关联。
5. 通知系统去重、用户隔离、点击联动和应用通知 API。
6. pacman 扩展平台、依赖和自动更新。
7. 原生托盘劫持可行性评估，独立于核心发布节奏。
